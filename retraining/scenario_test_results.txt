NOTE on Scenario C (23.0% vs expected <20%):
This dataset now carries 12% deliberate label noise to simulate real classroom
ambiguity (see generate_corrected_data.py) rather than a deterministic,
100%-clean label rule. The tradeoff: the model is very slightly less
overconfident on clean-looking cases too, including this one. This is a
false-positive-direction miss (over-cautious on a fine student), not a missed
struggling student — per RecommendationGenerator/AcademicEscalation's own
stated philosophy, a false alarm costs a teacher one question, while a missed
struggling student is the failure this product exists to prevent. Not re-tuned
back under 20% on purpose: doing so by further weighting this exact scenario
would reintroduce the same overfitting-to-test-points problem the first
(deterministic) version of this dataset had.
